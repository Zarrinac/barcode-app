# مستندات بتا Barcode Warehouse

## معرفی

Barcode Warehouse نسخه بتای یک برنامه ثبت و مدیریت بارکد انبار است که برای استفاده کارکنان دفتر و انبار طراحی شده است. برنامه اصلی با Next.js ساخته شده و نسخه اندروید با Capacitor صفحه اسکنر وب را داخل یک پوسته اندروید باز می‌کند.

آدرس صفحه اسکنر در نسخه اندروید:

```txt
http://bcrs.dcode.co.ir/scanner?freshLogin=1
```

## محدوده نسخه بتا

- ورود کاربران با حساب‌های تعریف‌شده.
- مدیریت مدل‌های کالا.
- مدیریت رکوردهای سریال.
- جمع‌آوری بارکد برای ثبت ورود کالا.
- اجرای صفحه اسکنر در اندروید با Capacitor.
- ذخیره یا خروجی اکسل از ردیف‌های اسکن‌شده.
- ذخیره اطلاعات در PostgreSQL با Prisma.
- استفاده از nginx به عنوان reverse proxy جلوی سرور Next.js.

## تکنولوژی‌های استفاده‌شده

- Next.js 16
- React 19
- TypeScript
- PostgreSQL
- Prisma
- Material UI
- Capacitor برای اندروید
- nginx برای reverse proxy

## بخش‌های اصلی برنامه

### داشبورد وب

داشبورد اصلی از مسیر زیر در دسترس است:

```txt
/
```

این بخش برای مدیریت مدل کالا، رکوردهای سریال، جستجو، فیلتر تاریخ و خروجی گرفتن از اطلاعات استفاده می‌شود.

### صفحه اسکنر

صفحه اسکنر از مسیر زیر در دسترس است:

```txt
/scanner
```

این بخش برای کار با موبایل یا اپلیکیشن اندروید بهینه شده است. کاربر وارد حساب خود می‌شود، اطلاعات سند و مشتری را ثبت می‌کند، بارکدها را اسکن می‌کند و در پایان رکوردها را به سرور ارسال می‌کند.

## اپلیکیشن اندروید

اپلیکیشن اندروید با Capacitor ساخته شده است. این اپلیکیشن یک پوسته اندروید است که صفحه اسکنر وب را باز می‌کند و بازنویسی کامل Native نیست.

آدرس سرور نسخه بتا با متغیر زیر تنظیم می‌شود:

```env
CAPACITOR_SERVER_URL="http://bcrs.dcode.co.ir/scanner?freshLogin=1"
```

برای ساخت APK نسخه بتا:

```powershell
$env:CAPACITOR_SERVER_URL="http://bcrs.dcode.co.ir/scanner?freshLogin=1"
npm run android:apk
```

فایل APK در مسیر زیر ساخته می‌شود:

```txt
android/app/build/outputs/apk/debug/app-debug.apk
```

## خلاصه استقرار

این برنامه باید به صورت Node.js server اجرا شود، چون از API route های Next.js و Prisma/PostgreSQL استفاده می‌کند. برنامه نباید به صورت static export منتشر شود.

روند کلی استقرار:

```bash
npm ci
npm run db:deploy
npm run build
npm run start:prod
```

nginx باید درخواست‌های عمومی را به آدرس زیر هدایت کند:

```txt
http://127.0.0.1:3000
```

جزئیات کامل‌تر در فایل `DEPLOYMENT.md` نوشته شده است.

## نکات نسخه بتا

- این نسخه برای استفاده کنترل‌شده در دفتر و انبار است.
- قبل و هنگام تست بتا از دیتابیس بکاپ بگیرید.
- رمزهای پیش‌فرض کاربران را قبل از انتشار گسترده تغییر دهید.
- نسخه فعلی اندروید از `http://` استفاده می‌کند؛ برای نسخه Production عمومی بهتر است `https://` فعال شود.
- بازخورد کاربران درباره سرعت اسکن، خطاهای بارکد، ورود به سیستم و کمبودهای فرآیند جمع‌آوری شود.
