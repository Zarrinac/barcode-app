# مستندات فنی Barcode Warehouse

## معرفی

Barcode Warehouse یک سیستم مدیریت و جمع‌آوری بارکد انبار است که با استفاده از Next.js، PostgreSQL، Prisma و Capacitor توسعه داده شده است.

این سیستم برای محیط‌های انبار و دفتر طراحی شده تا فرآیند جمع‌آوری بارکد، ثبت سریال و مدیریت اطلاعات کالا را سریع‌تر و متمرکزتر کند.

سیستم شامل بخش‌های زیر است:

- داشبورد وب
- صفحه اسکن بارکد
- اپلیکیشن اندروید
- دیتابیس PostgreSQL
- استقرار روی سرور اختصاصی

---

## معماری سیستم

ساختار کلی سیستم به صورت زیر است:

```txt
کاربر
 ├── مرورگر دسکتاپ
 ├── مرورگر موبایل
 └── اپلیکیشن اندروید

            ↓

سرور Next.js
 ├── داشبورد مدیریت
 ├── صفحه اسکن
 ├── API
 └── احراز هویت

            ↓

PostgreSQL Database
            ↓

Prisma ORM
```

## بخش‌های برنامه

### داشبورد وب

مسیر:

```txt

```

این بخش برای استفاده در کامپیوتر و تبلت طراحی شده است.

قابلیت‌ها:

- مدیریت مدل کالا
- مدیریت رکوردهای سریال
- جستجو و فیلتر
- خروجی اکسل
- ویرایش اطلاعات
- عملیات مدیریتی

---

### صفحه اسکن

مسیر:

```txt

```

این بخش برای:

- اسکنرهای اندرویدی
- مرورگر موبایل
- عملیات سریع انبار

فرآیند معمول کار:

1. ورود کاربر

## دستورات Prisma

### بروزرسانی Schema

```bash
npm run db:push
```

### Migration در Production

```bash
npm run db:deploy
```

### تولید Prisma Client

```bash
npx prisma generate
```

### ایجاد اطلاعات اولیه توسعه

```bash
npm run db:auth:seed
```

## متغیرهای محیطی

فایل:

```txt
.env.local
```

را از روی:

```txt
.env.example
```

ایجاد کنید.

نمونه متغیرها:

```env
DATABASE_URL=
NEXTAUTH_SECRET=
NEXTAUTH_URL=
CAPACITOR_SERVER_URL=
```

اطلاعات محرمانه را داخل Git قرار ندهید.

---

## اپلیکیشن اندروید

اپلیکیشن اندروید با Capacitor ساخته شده است.

این APK صفحه اسکنر سرور را داخل یک پوسته اندروید اجرا می‌کند.

### ساخت APK

```bash
npm run android:apk
```

### ساخت APK برای سرور اصلی

```powershell
$env:CAPACITOR_SERVER_URL="https://your-domain.com/scanner"
npm run android:apk
```
